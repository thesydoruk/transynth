# Starfield → українська

Офіційної української локалізації Starfield немає; канон — власний, складений у перекладі
2026-11 (базова гра, Shattered Space, офіційні Creations). Загальні правила живої української
(кальки, русизми, канцелярит) — ті самі, що у
[fo4-uk-translate/references/living-ukrainian.md](../fo4-uk-translate/references/living-ukrainian.md);
рід, ти/ви, голоси й терміни з FO4-скілу тут **не** діють — у Starfield свої.

## Джерела правди

| Що                                         | Де                                                                                                              |
| ------------------------------------------ | --------------------------------------------------------------------------------------------------------------- |
| Тон, транслітерація, ядро термінів         | [references/canon.md](references/canon.md)                                                                      |
| "Ти / ви" по персонажах (171 пара)         | [references/registers.md](references/registers.md)                                                              |
| Терміни                                    | `src/games/creation-engine/data/glossary/sf1-uk.ts` — seed; живий глосарій — таблиця `glossary`, `game = 'sf1'` |
| Імена, локації, фракції, квести — як у грі | `src/games/creation-engine/data/names/sf1-uk.json`                                                              |
| Рядки, сусіди, мовці, поточний переклад    | прод-БД `localizer`, лише читання (доступ — `CLAUDE.local.md`); контекст сцени будує `npm run review:batches`   |

Канонічну назву вживай саме в цій формі (відмінюючи), навіть у репліках. Канон хибний — лиши
його в рядку й скажи про це. Назви без канону транслітеруй за [canon.md](references/canon.md)
§4, однаково по всьому тексту, і перелічи у відповіді (`en → uk`), щоб внести в канон.

## Як працювати

1. **Збери контекст**: сцена чи квест, 2–5 реплік до й після, мовець і адресат з родом. Діалог
   читай цілою сценою, в порядку розмови.
2. **Перекладай шарами**, пізніший не скасовує попередній:
   зміст → канон (глосарій, імена) → голос персонажа → жива українська → ти/ви → рід.
3. **Редагуючи готовий переклад — правь, а не переписуй**: точний, живий рядок із правильним
   родом і регістром не чіпай.
4. **Перевір себе** за чеклістом нижче.
5. **Запис у базу — лише на пряму команду**, скілом `translation-apply`.

## Головні правила (деталі — у довідках)

- **Рід** — найважливіше. Герой без голосу, один текст на всіх: репліка героя
  (`speaker_gender: any`) і репліка до героя (`addressee_gender: any`) не маркують рід — ні "я
  згоден / був / сам", ні "ти готовий / могла". Ховай перефразом. Слеш, дві статі підряд і
  "ви" як милиця — заборонено. 45 реплік гра розгалужує сама — їх за їхнім займенником.
  → [gender-register.md](references/gender-register.md)
- **Ти/ви** — за персонажем: Сузір'я, супутники, Вільні Зірки, пірати, вулиця — "ти"; влада й
  командування ОК, корпорації, Дім Ва'руун, прилавок, роботи — "ви". Пара тримає один регістр
  у всіх сценах. → [gender-register.md](references/gender-register.md)
- **Жива українська**, не підрядник — довідка FO4-скілу `living-ukrainian.md`.
- **Голос**: стримана наукова фантастика; характер — у ритмі й лексиці, акценти не калічити.
  → [voices.md](references/voices.md)
- **Тип тексту** визначає свободу: діалог і проза — адаптація; цілі квестів — наказ на "ти",
  журнал — нейтрально від першої особи; назви й інтерфейс — точний термін і один шаблон на
  серію. → [text-types.md](references/text-types.md)
- **Технічне**: теги й плейсхолдери недоторканні; лапки ASCII `"…"`; теги реплік героя
  (`[Persuade]` → `[Переконати]`) — у дужках і за каноном; кличний відмінок; звання в реченні
  з малої. → [text-types.md](references/text-types.md)

## Чекліст

- Зміст: заперечення, суб'єкт/об'єкт, ідіома, жарт на місці; нічого не дописано й не викинуто.
- Рядок героя / до героя читається однаково за "він", "вона" й "вони".
- Регістр той самий, що в решті сцени для цієї пари.
- Канонічні терміни й імена — в канонічній формі; жодної лексики Fallout.
- Теги, плейсхолдери, `\n`, кінцева пунктуація, капіталізація як у джерелі.
- Репліка героя не довша за оригінал; `timing_sensitive` не роздуто.
- Порожній EN — не чіпано.
