# Рід і "ти / ви"

## Рід мовця і адресата

Гравець — Нейт **або** Нора; одна й та сама репліка звучить за обох. Рід беруть лише з полів
`speaker_gender` / `addressee_gender` (`male` / `female` / `any` / `unknown`) або з
розщеплення в самому EN. Не вгадуй з імені, професії, звання чи тону.

### Репліка гравця: `kind: prompt` або `speaker_gender: any`

Жодної форми, що маркує рід мовця: ні "я був / згоден / втомився / знайшла / радий /
впевнений / повинен / сам", ні дзеркальних жіночих. Переписуй **конструкцію**, не стать:
спершу теперішній час ("чекаю", не "чекав"), далі наказ, стан, іменник, безособове, результат.

| EN                                   | Погано                    | Так                                      |
| ------------------------------------ | ------------------------- | ---------------------------------------- |
| I agree                              | Я згоден                  | Гаразд                                   |
| Got it                               | Зрозумів                  | Зрозуміло                                |
| I was a soldier                      | Я був солдатом            | До війни — армія                         |
| I haven't found anyone yet           | Ще нікого не знайшла      | Ще нікого                                |
| Not Sure I Can                       | Не впевнений              | Ще не ясно, чи зможу / Не факт, що вийде |
| I'm tired                            | Я втомився                | Я вже без сил                            |
| I was surprised                      | Я був здивований          | Мене це здивувало                        |
| I was used to it                     | Я до цього звик           | Це вже було звичкою                      |
| I guess I just thought it would stay | Я просто думав            | Мені здавалося, що так і лишиться        |
| I knew                               | Я знав                    | Це було відомо                           |
| I Let Them Go                        | Я їх відпустив            | Відпустити їх                            |
| Then I'm glad I opened the door      | Тоді я радий, що відчинив | Тоді добре, що двері відчинили           |
| I've been waiting for you            | Я чекав                   | Я вже давно на тебе чекаю                |
| I'm glad you came                    | Я радий, що ти прийшов    | Добре, що ти тут                         |
| I thought you were dead              | Я думав, що ти помер      | Здавалося, тебе вже немає серед живих    |
| I appreciate you saying that         | Дякую, що сказав          | Дякую за ці слова                        |
| It wasn't what I expected            | Я не чекав                | Не те, на що можна було розраховувати    |

Рід маркують і **іменники та займенники**: "я герой", "я солдат", "сам / один / перший /
єдиний", "брехун", "дурень". "I'm a hero?" → "Героїзм — це про мене?" Перевір: чи звучить
рядок за Нору?

### Репліка до гравця: `addressee: Player`, `addressee_gender: any`

Не "ти готовий / готова / міг / допомогла / прийшов / сам / один / впевнена / правий /
перший / брехун". Ховай перефразом, **не** через "ви".

| EN                                             | Так                                   |
| ---------------------------------------------- | ------------------------------------- |
| Are you ready?                                 | Ну що, рушаємо?                       |
| You've been to a Vault?                        | Тобі вже доводилося бувати у Сховищі? |
| For all you've done you deserve it             | За всі твої заслуги це твоє по праву  |
| Be careful out there                           | Бережи себе                           |
| You look tired                                 | Схоже, тобі нелегко                   |
| You're a two-faced liar!                       | Ти — дволична людина!                 |
| You first                                      | Тобі вперед / Починай                 |
| Where are you goin'?                           | Куди це ти?                           |
| You came to visit!                             | Ти в гостях!                          |
| You've certainly got the Institute's attention | Інститут уже звернув на тебе увагу    |
| whenever you're ready                          | Як зберешся — рушай                   |
| You were a big help                            | Без тебе б не витягли                 |
| You saved me                                   | Завдяки тобі я ще тут                 |
| You're right                                   | Так і є                               |
| You're not alone                               | Не лише тобі так                      |
| How could you forget?                          | Як можна було забути?                 |
| It's your call                                 | Тобі вирішувати / Діло твоє           |

Наказ і майбутній час рід не маркують: "Дивись", "подивишся" — так; "зібрався" — ні.

### Заборонені милиці

- Слеш: "зробив/ла", "обережним/обережною".
- Дві статі підряд: "Будь обережною. Будь обережним."
- "Ви" / "будьте" замість "ти" лише щоб сховати рід.

### Коли рід лишається

- `speaker_gender: male/female` (NPC або стать-специфічна репліка гравця): Пайпер "я була там",
  Нік "я бачив". Не нейтралізуй відомий рід — це збіднює мову. Так само адресат із відомою
  статтю: до синтки "ти вільна йти".
- EN сам розщеплює: sir/ma'am, Шон → mom/dad, "чоловік"/"дружина", Cooke → Paul, Срібний
  Плащ → Пані Таємниць. Це окремі рядки — рід лишай. Пари sir/mum правлять однаково, крім
  самого звертання.
- `unknown`, але зі сцени стать очевидна (`ctx: "Piper"`, у сцені "вона") — можна узгодити,
  обережно; не випливає — пиши нейтрально.
- Записки: `narrator_gender` відомий — "я писала"; невідомий — не вигадуй, але перевір, що рід
  збігається з підписом.

### Звертання й фемінітиви

- "Blue" від Пайпер → **"Блу"**: невідмінюване, без роду, ніколи "Синій/Синя".
- Пестливі до гравця (honey, sweetheart, dear, darling, hon) → "сонечко", "золотко",
  "серденько"; **ніколи** "любий/люба" до людини. "My dear" → "моє золотко". До предмета чи
  третьої особи ("любий Піп-бой") — можна.
- "Sir" → "сер" (Кодсворт, X6-88, Братерство, зброєносці); "ma'am / madam / mum" → "пані" /
  "мадам", не "пане" і не "мама".
- Фемінітиви для жінок у посадах і професіях: докторка (Докторка Лі, Докторка Амарі),
  професорка, прокторка (Прокторка Інграм), писарка (Писарка Гейлен), агентка, лікарка,
  барменка, поселенка, торговка, охоронниця, наглядачка, доглядальниця, сусідка.
- Військові звання жінок — у чоловічій формі: лицар, паладин, страж, старійшина, сержант,
  капітан, генерал, пілот (Лицар Люсія).

## "Ти" / "ви"

Пустка Співдружності — на **"ти"**. "Ви" — рідкісний виняток там, де персонаж справді тримає
дистанцію чи субординацію. Сумніваєшся — "ти". Масове переведення сцен на "ви" — помилка
(у вичитці це вже виправляли окремим проходом).

**"Ви" до гравця — тільки:**

- Інститут: вчені, Отець, докторка Лі, Амарі, X6-88;
- Кюрі;
- старійшина Мексон і капітан Келлс — холодна субординація;
- Кодсворт-компаньйон — манірний дворецький: "сер", "пані";
- мер Макдоно — лицемірна політична ввічливість;
- довоєнні записи, реклама, офіційні повідомлення; довоєнні службовці й роботи-службовці у
  формальній ситуації (Галерея General Atomics, Протектрон-охоронець).

**"Ти" до гравця — усі інші:** компаньйони (Нік, Пайпер, Кейт, Генкок, Маккріді, Стронг,
Дікон, Ада, Данс, Престон, Лонґфеллоу, Гейдж); **Братерство, крім Мексона й Келлса** — Данс,
Ріс, Гейлен, Інграм, Квінлан, Тіган, Кейд, Нерія, Брендіс, лицарі, зброєносці, писарі, пілоти
(по-військовому прямо: "Доповідай, лицарю", "Вільно"); рейдери, Атомні коти, Мінітмени, Діти
Атома, поселенці, крамарі, Добросусідство, Даймонд-сіті, Ядер-Світ, трапери, Підземка
(Дездемона, Дікон, Том, Каррінгтон, Глорі), Мама Мерфі; інші Mr. Handy (крамниця, Сховище 81).

**Гравець до NPC:** до всіх — "ти", крім вчених Інституту, Лі, Амарі, X6-88, Кюрі,
Кодсворта, Мексона й Келлса — "ви". **Отець (Шон)** — окремо: гравець до нього на "ти"
("Я досі тебе люблю, сину"; рішення користувача 2026-10-24), Отець до гравця — на "ви".

**Множина "ви"** лишається, коли адресатів кілька: you guys, you all, натовп, радіо, диктор,
проповідь, оголошення. Не "всі ти" про Учениць.

**Одна сцена — один регістр** для пари мовець–адресат, і в межах однієї репліки теж
("Можете… Знайте", не "Можете… Май на увазі"). Персонаж не з ви-списку вже послідовно на "ти" —
не переводь на "ви"; із ви-списку, а стоїть "ти" — переводь.

### Після заміни ви→ти

Сліпа заміна ламає рід і число. Перевір і перефразуй:

| Погано                 | Так                                                           |
| ---------------------- | ------------------------------------------------------------- |
| Твій повернення        | Твоє повернення                                               |
| Твоє час               | Твій час                                                      |
| ти прийшли / перемогли | безособове: "твоя взяла", "рішення прийнято", "по яку справу" |

Не лишай "ти" + дієслово множини, і не повертай "ви", щоб сховати рід.
