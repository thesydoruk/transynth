# Sim Settlements 2

Моди 120–123: основний плагін, розділи 2 і 3, Extended — 121 728 рядків. Фінальна вичитка
2026-10-29/30 змінила 43 % прочитаних рядків (узгодженість, регістр, канон; переклад був
машинний). Порядок джерел: канон FO4 (`fo4-uk.json`) → цей файл →
`doc/reviews/ss2-uk-2026-10-29/SS2_CANON.md` (повний список: 559 імен, ~90 термінів). Де
`DECISIONS.md` суперечить канону, перемагає пізніше рішення й уніфікація (README §5) — тут узгоджено.

## Транслітерація й латиниця

- Як у FO4: h → г (Hagen → Гейген), w → в, th → т, -son → -сон, Mc/Mac → Мак- (Макнамара,
  Мактавіш, Маккендрік); подвоєння лишай (Глаттон, Магнуссон, Джерред, Гріффін).
- Прізвисько з жартом перекладай (Fishfood → Риб'ячий Корм, Eric The Alright → Ерік Непоганий,
  Viceroy → Віцекороль, Sickle → Серп); ім'я-слово лишай іменем (Sneake → Снік, Carnal → Карнал).
- Латиницею: автори планів (kinggath, Ohnno, frogprincess, Tinuvia…; регістр як в EN), назви
  модів і доповнень (Sim Settlements 2, Industrial Revolution, Workshop Framework), теги `[SS2]`
  `[IR]` `[CQ]` `[SS2C3]`, абревіатури ASAM, CPD, NLTC, GNN, RobCo, FEV, G.E.C.K., F4SE, HUD,
  роботи M.A.L.A., O-M-0R, F.I.D.O.; усталене «РобКо Фан» з канону FO4 не чіпай.
- Ванільне — за каноном FO4, навіть якщо в SS2 інакше: Castle → Форт (не «Замок»), Vault →
  Сховище, Vault-Tec → Волт-Тек (однина, ж. р.), Vertibird → вертіберд, Wasteland → Пустка.

## Регістр і звертання

- Усі персонажі SS2 до гравця на «ти», і гравець до них на «ти». «Ви» — лише: RobCo Роб і
  рекламні голоси ASAM/RobCo; персонал і комп'ютери Волт-Тек (Медісон, протектрон); довоєнні
  роботи-службовці у формальній ролі (Барнабі, Реджинальд, Янус — синт із протокольною мовою);
  вчені Залишків Інституту (Салліван, Галістер); Мексон і X6-88 за FO4; множина (натовп,
  гучномовець, проповідь, дошка оголошень). Гравець до Януса/Барнабі — «ти».
- Звертання до гравця: Chief → «шефе» (ж. мовець про себе — «шефиня»), Boss → «босе»,
  Overseer → «наглядачу», Sir → «сер», General → «генерале», Director (Салліван) →
  «директоре». Partner (Джейк про гравця) маркує рід — перефразуй («ми працюємо разом»).
- Безродові звертання: dummy → «дурна голово», pipsqueak → «дрібното», hon → «сонечко»; Jake:
  Slick → «розумнику», Darlin' → «золотко»; Ron: baby / cool cat → «крихітко»; Cleff: Slick → Слік.
- Пари NPC: Джейк → Магнуссон, Старий Пол, Алджернон — «ви», вони до Джейка «ти»; Лупе → старші
  «ви»; Лідія → Рон / Глаттон / Алісон / Генкок «ви», вони до неї «ти»; Айзек ↔ Ламонт «ви»;
  Шенді до дорослих «ви». Одна сцена — один регістр.
- `speaker_gender` у SS2 часто хибний (Theresa, Alex Chang, Lupe, Aiden, Mansfield, Wise,
  Ellis, Algernon) — рід бери з тексту сцени. Голос `playervoicefemale` = репліки гравця, без
  роду; гілки Slick (лише Нейт) і Nora-only лишають рід.
- Лайка за EN: fuck → «блять», shit → «лайно», damn → «чорт» / «прокляття». Не вигадуй. Метадані
  адресата теж бувають хибні (Лідія → Allison): репліка за змістом до гравця — «ти» без роду.

## UI, MCM, плейсхолдери

- Теги в дужках під захистом `UI_BRACKET_TAGS` (`[Conversion]`, `[Skilled]`, `[Hi-Tech Farm]`,
  `[Requires Gifted Endurance]`) усередині тексту лишаються латиницею (відкрите питання).
  Окремий рядок-мітка рівня SPECIAL — [Аматор] / [Вправний] / [Обдарований] / [Савант]; перки в
  дужках — за FO4 ([Знавець зброї], [Експерт з вибухівки], [Обізнаність], [Міцна спина]);
  ранг — «[<перк>, ранг N]».
- Лапки: у SS2 стоять прямі `"…"` (3 362 рядки), FO4 після проходу 2026-10-24 — «». Нові
  правки пиши ASCII `"…"`, як вимагає скіл; масову заміну на «» не роби (README §6).
- Недоторканні: `<Token…>`, `<Alias…>`, `<Global…>`, `#DepartmentInitial`, `%.0f`, `L1/L2`,
  `2x2`, `Mk. I`, `<< ERROR >>`, HUD-виклики `| SS2HUD.swf | …` (лише EN), `<font>`. Масок
  `¤PH¤` у перекладі бути не може — це зламаний перенос рядка.
- Кнопки — регістр як в EN: TRADE / BARTER → ТОРГУВАТИ, MAYBE → МОЖЛИВО, NOT INTERESTED → НЕ
  ЦІКАВО, NO THANKS → НІ, ДЯКУЮ, Never mind → Неважливо, Yes, Do It → Так, виконати, No,
  Nevermind → Ні, не треба, Nevermind, Don't Use This → Ні, не використовувати.
- Мітки: SPEECH PASS/FAIL → ПЕРЕКОНАННЯ: УСПІХ/НЕВДАЧА, Pass/Fail → (успіх)/(невдача), Male/Female
  PC → Гравець-чоловік/жінка, (Optional) → (Необов'язково), ON/OFF → УВІМК./ВИМК.
- MCM / Менеджер міста: Info Box → Інформаційне вікно, Status Meters → Індикатори стану,
  Gameplay → Ігровий процес, Quest Credits → Титри квестів, Bypass Locks → Обхід блокувань;
  довідка й повідомлення — на «ти», безособово; назви об'єктів Майстерні — « — ».

## Відкриті питання (вирішує користувач, не вирішуй сам)

1. Теги в дужках латиницею (`[Conversion]`, `[Skilled]`, `[Gifted]`…) — перекладати?
2. Мінітмени до Генерала: FO4 — «ви» + «пане», SS2 — «ти» + «сер». Зводити до FO4?
3. NLTC Board — «Рада» (20) проти «Правління» (9); пізнє рішення в `DECISIONS.md` каже
   «Правління», але в базі не мінялося.
4. Синти Підземки до гравця — «ви» за аналогією з Янусом чи «ти», як Аякс.
5. Лапки: провести прохід `"…"` → «» для SS2, як для FO4?
6. Flap Limb — канон «тремтіння кінцівок», за текстом кінцівки обвисають («відвисання»?).
7. Mark-декалі — «Марка N» (29) і «Маркування N» (20) змішані; канон каже «Маркування».
8. Intelligence — ~130 рядків «Інтелект» (SPECIAL); лише кімнату відділу змінено на «Розвідка».
9. Рядок 8136500 (ARMO DESC): EN — лише перенос рядка, переклад — вигадана «Університетська
   сукня»; `translations:apply` не пише переклад із самих пробілів — потрібне ручне рішення.
