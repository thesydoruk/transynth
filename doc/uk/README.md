# Transynth — Вікі проєкту

**Transynth** — відкритий self-hosted тулчейн для локалізації ігрових модів:
імпорт, пам’ять перекладів, локальний LLM, рев’ю і синтез реплік в одному
застосунку. Bethesda і Disco Elysium вже є; інша гра — здебільшого новий профіль.

Ця вікі охоплює і **користувацькі сценарії**, і **технічну документацію проєкту**.
Частина сторінок написана для перекладачів, частина описує архітектуру, рантайм
та інструменти розробки.

## Короткий огляд

Конвеєр, разом з опційною озвучкою, виглядає так:

```text
Імпорт мода (ESP/BA2)
   ↓
Автоматичний TM-match ←── Translation Memory (точне / anchor перевикористання)
   ↓
Пакетний LLM-переклад ←── OpenAI / vLLM
   ↓
Людське рев’ю у вебредакторі
   ↓
Перевірка QA ←── 9 типів проблем + конфігуровані правила
   ↓
Озвучка (опційно) ←── Fish Speech + референсне аудіо гри
   ↓
Експорт (STRINGS / patched ESP / BA2 / langpack)
```

## Підтримувані ігри

Transynth підтримує такі ігри:

- Fallout 4 (`fo4`)
- Fallout 76 (`fo76`)
- Fallout 3 (`fo3`)
- Fallout: New Vegas (`fnv`)
- The Elder Scrolls IV: Oblivion (`ob`)
- The Elder Scrolls III: Morrowind (`mw`)
- Skyrim Special Edition (`sse`)
- Skyrim Legendary Edition (`sle`)
- Disco Elysium Final Cut (`disco`)

Поведінка архівів/експорту залежить від профілю гри:

- FO4 / FO76: BA2-потік
- FO3 / FNV / OB / MW / SSE / SLE: BSA-потік
- Disco Elysium: мовні пакети Disco Translator Final Cut (`.po` + `.wav`)
