# Конвеєр локалізації Fallout 4 — Вікі проєкту

Ласкаво просимо до документації **Fallout 4 Localization Pipeline** — вебплатформи для перекладу модів Fallout 4 і супроводу всього локалізаційного тулчейна.

Ця вікі тепер охоплює і **користувацькі сценарії**, і **технічну документацію проєкту**. Частина сторінок написана для перекладачів та рев'юерів, а частина описує архітектуру, компоненти рантайму та інструменти розробки.

## Короткий огляд

Конвеєр покриває повний цикл локалізації мода Bethesda:

```text
Імпорт мода (ESP/BA2)
   ↓
Автоматичний TM-match ←── Translation Memory (5-методний waterfall)
   ↓
Пакетний LLM-переклад ←── OpenAI / Ollama
   ↓
Людське рев’ю у вебредакторі
   ↓
Перевірка QA           ←── 9 типів проблем + конфігуровані правила
   ↓
Експорт (STRINGS / patched ESP / BA2)
```
