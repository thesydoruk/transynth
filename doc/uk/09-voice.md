# 09 — Озвучка

Синтез локалізованої озвучки з готових перекладів. Transynth клонує оригінального
мовця через зовнішній сервіс **Fish Speech**, далі пакує аудіо для ігор Bethesda
(FUZ / LIP) або пише WAV для Disco Elysium.

Для ліпсинку потрібна легальна копія гри (і зазвичай Creation Kit). Див.
[THIRD_PARTY.md](../THIRD_PARTY.md).

## Що потрібно

1. **Перекладені репліки.** Синтез бере поточний текст цільовою мовою.
   Неперекладені й пропущені рядки пропускаються.
2. **Референсне аудіо** з імпортованого мода (і, для Bethesda, голосових архівів
   гри). Імпорт розпаковує `*Voices*.ba2` / BSA у дерево `Sound/Voice/`.
3. **Fish Speech** на `TTS_BASE_URL` (див. `.env.example`). URL у UI лише для
   читання — змінюйте в `.env` і перезапускайте.
4. **audio-intel** на `AUDIO_INTEL_BASE_URL` (Whisper, окремо від TTS). Для
   Disco потрібен, щоб відрізати закадровий текст від озвучених лапок. Без
   сервісу рядок іде в TTS цілком. Кеш транскриптів — `AUDIO_INTEL_CACHE_DIR`
   (типово `data/cache/audio-intel`). Compose audio-intel не піднімає —
   лише URL у `.env`.
5. **Інструменти озвучки** для ліпсинку Bethesda: `npm run tools:install` або
   `docker compose --profile tools run --rm cli npm run tools:install`.
   Ставляться FaceFXWrapper, дані Fonix і xWMAEncode у `data/tools/voice/`.

Disco Elysium не використовує FaceFX. Синтезовані репліки — WAV у експортованому
мовному пакеті Final Cut. Перегенерація одного рядка теж іде через WAV, не
через Bethesda FUZ / LIP.

## Режим Voice

Відкрийте мод і перемкніть тулбар на **Voice**
(`?mode=voice` на `/games/:gameId/mods/:id`).

Режим є і в Bethesda, і в Disco. У Disco **немає** вкладки Dialogs і немає дій
INNR / визначення статі.

Ліва колонка — **мовці**. Пошук фільтрує список. Права — репліки мовця: оригінал,
переклад, відтворення оригіналу / синтезу і перегенерація одного рядка.

Фільтри ховають рядки, у яких уже є аудіо, ще немає перекладу або вже є
локалізований тейк. У підвалі — гарячі клавіші (як у Dialogs: `↑`/`↓`, `N`
наступна незавершена, `P` відтворення, `Enter` редагування).

## Відтворення в Dialogs

У іграх Bethesda вкладка **Dialogs** також грає оригінал і синтез у транскрипті.
Якщо референсу немає, замість кнопки перекладу показується причина пропуску.
Редагування транскрипту описане в [Редакторі](03-editor.md).

## Запуск синтезу

Круглий контроль **Voice** на тулбарі редактора (і той самий на списку модів)
запускає джобу `voice-generate`:

- **Missing** — лише репліки без локалізованого тейку.
- **All** — перегенерувати всі озвучені репліки для поточної мовної пари.

Прогрес стрімиться під час джоби. Зупинити можна тим самим контролем.

Перегенерація одного рядка в режимі Voice відкриває невелике вікно (лишити
поточні параметри референсу або перевизначити line-reference для цього тейку).

Для Bethesda результат пишеться в `_localize_{hash}/{lang}/` поруч з імпортом,
а не в розпакований англійський голосовий архів. Disco пише локалізовані
`.wav` у дерево langpack.

## Disco: що саме озвучується

Lockit часто змішує репліку в лапках і закадровий текст
(`She says, "Okay."`). Раніше рішення бралося з довжини кліпу; тепер —
з транскрипту **audio-intel** (Whisper) англійського WAV.

- Якщо в транскрипті є характерні слова закадрового тексту — TTS озвучує
  **весь** рядок.
- Якщо цих слів немає (актор сказав лише лапки) — TTS ріжеться до відповідних
  quote-span у перекладі. Кілька лапок можуть звузитися до однієї, якщо ASR
  збігається лише з тим індексом.
- Сервіс недоступний або кешу немає — рядок лишається цілим, окрім випадку
  `"A." She… "B."`: середній закадровий шматок між двома лапками ніколи не
  в кліпі, тож озвучуються лапки.
- Порожній транскрипт від живого сервісу (кліп майже без мови) теж ріже до
  лапок: прозу Whisper завжди розпізнає.
- Низька впевненість ASR може відкинути закадровий текст, але **не** вибирає
  одну лапку з кількох.

Перед TTS Disco ще:

- розгортає курсив `*слово*` у звичайні слова (це не Fallout-ремарка);
- знімає UI-дужки `[Leave.]`;
- відновлює зірчасту цензуру lockit (`f****t` → повне слово), щоб голос
  і глосарій бачили той самий канон, що й LLM.

Деталі розмітки lockit — у [LLM-перекладі](06-llm-translation.md#disco-lockit).

## Налаштування

**Settings → Voice** (`/settings?tab=voice`):

| Контроль               | Де зберігається                           | Ефект                                                                          |
| ---------------------- | ----------------------------------------- | ------------------------------------------------------------------------------ |
| URL TTS-сервера        | `.env` `TTS_BASE_URL`                     | Лише читання в UI                                                              |
| URL audio-intel        | `.env` `AUDIO_INTEL_BASE_URL`             | Whisper для Disco spoken-span; у UI немає                                      |
| Паралелізм Fish Speech | `project_settings`                        | Максимум одночасних запитів synthesize (1–32)                                  |
| Line reference         | `project_settings` `voice.line_reference` | Клонувати з кліпу самої репліки, якщо він досить короткий; інакше — кліп мовця |
| Збіг таймінгу на гру   | `project_settings`                        | Підігнати довжину синтезу під оригінальну репліку                              |

Посилання **Voice** на хабі гри веде на цю вкладку, окремої сторінки немає.

## Відомі обмеження

- Якщо в імпорті кілька голосових BA2/BSA з однаковими внутрішніми шляхами
  `Sound/Voice/`, лишається **лише останній розпакований архів**.
  Синтез у `_localize_{hash}/{lang}/` цей крок не затирає.
- Окремий файл `.ba2` завантажити не можна. Покладіть голосові архіви поруч
  із плагіном у zip/7z/rar або дайте імпортеру знайти сусідні архіви.
- Хто дістався HTTP-порту, може витрачати бюджет TTS. Див.
  [SECURITY.md](../../SECURITY.md).
