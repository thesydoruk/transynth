## Огляд

Перед експортом система QA проходить по всіх перекладених рядках і позначає потенційні проблеми.

QA не блокує експорт, тобто технічно ви можете експортувати мод навіть із відкритими зауваженнями. Але перевірка цих прапорців суттєво підвищує якість фінальної локалізації.

---

## Як виконується QA-перевірка

Окремої кнопки `Run QA` немає.

QA запускається **автоматично**:

- кожного разу, коли ви зберігаєте переклад через `Ctrl+S`, `Ctrl+Enter` або зміну статусу;
- функція `refreshQAIssues` одразу перераховує проблеми для цього рядка;
- результати стають видимими на вкладці **QA** у Detail Panel.

Сигнали у UI:

- у translation column поруч із текстом може з’явитися маленький бейдж `N QA`;
- на вкладці **QA** для вибраного рядка показується повний список проблем;
- кожна проблема має severity і текст пояснення.

## Типи QA-проблем

| Тип проблеми                  | Internal key              | Severity      | Опис                                                                                                                                                                                                                                                                                                  |
| ----------------------------- | ------------------------- | ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Порожній переклад             | `empty_translation`       | Error         | Є source text, але translation порожній або складається лише з пробілів                                                                                                                                                                                                                               |
| Невідповідність placeholders  | `placeholder_mismatch`    | Error         | У перекладі відсутній, доданий або змінений placeholder                                                                                                                                                                                                                                               |
| Переклад дорівнює source      | `same_as_source`          | Warning       | Translation байт-в-байт збігається з source text                                                                                                                                                                                                                                                      |
| Підозріла різниця довжини     | `length_delta`            | Warning       | Translation більш ніж у 1.6 раза довший або коротший менш ніж у 0.5 раза                                                                                                                                                                                                                              |
| Заборонені control chars      | `forbidden_chars`         | Error         | Є невидимі керуючі символи, які гра не відрендерить                                                                                                                                                                                                                                                   |
| Порушення глосарію            | `glossary_violation`      | Warning       | У source є glossary term (з урахуванням меж слів — «iron» не збігатиметься з «environment»), але в translation немає очікуваного еквівалента                                                                                                                                                          |
| Неузгоджений рід              | `gender_mismatch`         | Error/Warning | Лише для української. Родова форма (минулий час чи предикативний прикметник) біля «я» або «ти» не збігається зі статтю мовця чи адресата з графа діалогів. Error — коли стать учасника відома, Warning — коли учасник є гравцем (його стать обирається у грі, тож жодна маркована форма не підходить) |
| Неузгоджений дублікат         | `duplicate_inconsistency` | Warning       | Однаковий `text_norm` інакше перекладений десь іще                                                                                                                                                                                                                                                    |
| Користувацькі forbidden chars | `forbidden_chars`         | Configurable  | Явно заборонені символи, задані правилом                                                                                                                                                                                                                                                              |
| Перевищення max length        | `max_length`              | Configurable  | Рядок довший за ліміт для цього типу запису або поля                                                                                                                                                                                                                                                  |

Placeholder extractor розуміє шаблони на кшталт:

- `%s`, `%d`;
- `{0}`, `{item}`;
- `<Alias=Player>`;
- `<b>`;
- `$PlayerName`;
- `[DIAL:001234AB]`.

Приклади:

```text
[placeholder_mismatch]
Source: "Hello, <Alias=Player>! You have {0} caps."
Translation: "Привіт! У вас є {0} кришок."
Issue: У перекладі відсутній <Alias=Player>.

[same_as_source]
Source: "Pip-Boy"
Translation: "Pip-Boy"
Issue: Переклад ідентичний source text.

[glossary_violation]
Glossary: synth → синт
Source: "Kill the synth."
Translation: "Убий синтетика."
Issue: Очікується використання терміна "синт".
```

## Рівні серйозності

У поточній реалізації існує лише два рівні — `Info` немає.

| Severity | Значення                                                 | Рекомендована дія       |
| -------- | -------------------------------------------------------- | ----------------------- |
| Error    | Напевно спричинить проблеми в грі або зламає дані        | Виправити до експорту   |
| Warning  | Ймовірно погіршить якість або вказує на підозрілий рядок | Виправити за можливості |

## Конфігуровані QA-правила

Частина QA-перевірок налаштовується окремими правилами.
Керування відбувається на сторінці **QA Rules** (`/qa-rules`).

### Заборонені символи

Правило `forbidden_chars` визначає набір символів, які не повинні з’являтися у перекладах у межах заданого scope.

Поле **Value** містить буквальний рядок із заборонених символів.
Кожен символ із цього рядка перевіряється окремо.

Приклад: значення `©®™` забороняє саме ці три символи.

Коли це корисно:

- якщо шрифт Fallout 4 не підтримує частину символів вашої локалі;
- якщо конкретні code points відображаються квадратами або silently drop-яться.

Scope можна звузити до конкретного:

- GRUP signature, наприклад `DIAL`;
- field path, наприклад `FULL`.

Якщо поля scope порожні, правило застосовується до всіх рядків.

### Максимальна довжина

Правило `max_length` задає максимально допустиму **кількість символів** для перекладу в певному scope.

Поле **Value** має містити ціле число, наприклад `128`.

Коли це корисно:

- короткі UI-елементи мають жорсткі обмеження простору;
- довгі переклади item names, NPC names або HUD labels обрізаються;
- різні поля (`FULL`, `DESC`, `SHRT`) мають різні practical limits.

Приклади scope:

| Signature | Path   | Max | Випадок використання |
| --------- | ------ | --- | -------------------- |
| `WEAP`    | `FULL` | 50  | Назви зброї          |
| `NPC_`    | `FULL` | 40  | Імена NPC            |
| _(any)_   | `DESC` | 512 | Поля описів          |

Підрахунок іде за символами, а не байтами.

## Робота з QA у редакторі

Окремого dropdown-фільтра `QA status` у редакторі немає.
Натомість QA-проблеми видно двома способами:

1. Через маленький бейдж `N QA` у translation column.
2. Через вкладку **QA** у Detail Panel.

Ефективний workflow:

1. Відфільтруйте рядки за статусом, наприклад `auto` або `tm`.
2. Під час перегляду таблиці шукайте бейджі `N QA`.
3. Клікніть по проблемному рядку і відкрийте вкладку **QA**.
4. Виправте текст у translation textarea.
5. Натисніть `Ctrl+S` — QA перераховується автоматично.
6. Рухайтеся далі клавішею `N` або `↓`.

## Сторінка QA Rules

Сторінка **QA Rules** (`/qa-rules`) показує всі наявні правила і дозволяє:

- переглядати правила в таблиці;
- створювати нові;
- редагувати будь-який рядок inline;
- вмикати або вимикати правило;
- видаляти його назавжди.

Поля форми додавання/редагування:

| Поле        | Обов’язкове | Опис                                                      |
| ----------- | ----------- | --------------------------------------------------------- |
| Rule type   | Так         | `Forbidden chars` або `Max length`                        |
| Signature   | Ні          | Обмеження до GRUP, наприклад `DIAL` або `NPC_`            |
| Path        | Ні          | Обмеження до поля, наприклад `FULL` або `DESC`            |
| Value       | Так         | Для `forbidden_chars` — символи, для `max_length` — число |
| Severity    | Так         | `error` або `warning`                                     |
| Description | Ні          | Людиночитний опис, який потрапляє в QA message            |

У поточному білді всі правила scoped до гри `fo4`.
