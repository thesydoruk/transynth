## Що таке Review Queue?

Review Queue — це сфокусований список рядків, для яких потрібне рішення людини.

Найкорисніші сценарії:

- після LLM batch translation, коли потрібно перевірити рядки зі статусом **Auto**;
- коли TM-matched переклади зі статусом **TM** ще не підтверджені;
- коли reviewer перевіряє чужу чернеткову роботу (**Draft**);
- коли потрібно почати з найменш упевнених рядків.

## Відкриття Review Queue

Перейдіть на сторінку **Review Queue** у верхній навігації або відкрийте маршрут `/review-queue`.

## Фільтри

Review Queue підтримує кілька фільтрів:

| Фільтр              | Опис                                                       |
| ------------------- | ---------------------------------------------------------- |
| **Target language** | Мова рев’ю: `uk`, `ru`, `de`, `fr`, `pl`; типово `uk`      |
| **Status**          | Чіпи: `Auto`, `Fuzzy`, `TM`, `Draft`; типово всі ввімкнені |
| **Mod**             | Один мод або `All Mods`                                    |
| **Max confidence**  | `All`, `<0.95`, `<0.85`, `<0.75`, `<0.60`                  |

Таблиця завжди показує **50 рядків на сторінку** й сортується за confidence за зростанням, тобто найменш надійні рядки йдуть першими.

### Confidence Scores

Кожен рядок має **confidence score** від `0` до `1`, який відображається як маленька смуга й відсоток.

| Джерело оцінки | Як формується                               |
| -------------- | ------------------------------------------- |
| **Fuzzy / TM** | Нормалізована text-similarity з TM lookup   |
| **Auto (LLM)** | Confidence, який повернув LLM provider      |
| **Unknown**    | Показується як `—` і сортується вниз списку |

Чим ближче score до `0`, тим уважніше цей рядок треба перевіряти.
Значення `1.0` зазвичай означає exact TM hit.

## Робота з чергою

1. Налаштуйте фільтри, наприклад залиште лише `Auto` і встановіть `Max confidence < 0.85`.
2. У toolbar видно лічильник рядків, що потрапили у вибірку.
3. Для кожного рядка таблиця показує:

| Колонка     | На що дивитися                                     |
| ----------- | -------------------------------------------------- |
| Mod         | До якого мода належить рядок                       |
| GRUP        | Тип запису, наприклад `DIAL`, `BOOK`, `WEAP`       |
| EDID        | Editor ID; це посилання для відкриття в Mod Editor |
| Source (EN) | Оригінальний текст                                 |
| Translation | Автоматичний або TM-підібраний переклад            |
| Status      | `Auto`, `Fuzzy`, `TM`, `Draft`                     |
| Conf        | Confidence bar                                     |
| QA          | Активні QA-попередження                            |

4. Далі для кожного рядка можливі дії:

- **Approve** — виставляє статус `reviewed`, після чого рядок зникає з черги;
- **Reset** — очищує переклад і повертає рядок у `empty` / untranslated state;
- **Edit in editor** — перехід до повного Mod Editor для ручного виправлення.

5. Пройдіть сторінки доти, доки черга не спорожніє або доки не залишаться лише рядки з достатньо високою надійністю.

---

## Review Queue vs. фільтри редактора

Обидва інструменти можуть показувати неперевірені рядки, але вони корисні для різних сценаріїв.

|                  | Review Queue                     | Editor Filter                   |
| ---------------- | -------------------------------- | ------------------------------- |
| **Scope**        | Усі моди разом                   | Один мод за раз                 |
| **Сортування**   | За confidence, найслабші першими | За будь-якою колонкою           |
| **Найкраще для** | Швидкий batch review             | Глибоке редагування одного мода |

Використовуйте **Review Queue** для регулярного review-pass після AI-перекладу.
Використовуйте фільтри **Editor** для детального редагування конкретного мода.
