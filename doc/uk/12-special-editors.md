## INNR Editor — Instance Naming Rules

**Маршрут:** `/games/:gameId/mods/:modId/innr`

INNR-записи керують тим, як гра генерує динамічні назви предметів, наприклад зброї з модифікаціями:

```text
Combat Rifle → Powerful Automatic Combat Rifle
```

INNR editor показує naming rules, згруповані за базовим EDID, і дозволяє перекладати окремі name slots.

### Як відкрити INNR Editor

У toolbar сторінки мода натисніть **INNR Editor**. Кнопка видима лише тоді, коли в моді є INNR-записи. Або відкрийте маршрут напряму.

### Як читати INNR grid

| Колонка     | Опис                                             |
| ----------- | ------------------------------------------------ |
| Slot        | Позиція в naming rule: prefix, noun, suffix тощо |
| EDID        | Базовий Editor ID правила                        |
| Source      | Оригінальний фрагмент назви                      |
| Translation | Ваш переклад цього фрагмента                     |

### Редагування слотів

Клікніть по рядку, щоб відредагувати поле Translation inline.

- `Enter` зберігає;
- `Escape` скасовує;
- blur поля теж запускає autosave;
- кнопка **Save** на рядку дублює збереження;
- кнопка **✕** очищує переклад повністю.

Поки є незбережені зміни, рамка input-поля стає помаранчевою. Після успішного save коротко підсвічується зеленим.

### Target language

У верхній частині сторінки є dropdown **Language**, через який можна перемикати мову, наприклад `uk`, `ru`, `de`, `fr`, `pl`.
Після зміни сторінка автоматично підтягує дані для нової мови.

### Як поєднуються слоти

INNR records визначають компоненти імені, які гра комбінує під час runtime.
Наприклад:

| Slot | Source       | Translation      |
| ---- | ------------ | ---------------- |
| 001  | Powerful     | Потужна          |
| 002  | Automatic    | Автоматична      |
| base | Combat Rifle | Бойова гвинтівка |

Фінальне ім’я:

```text
Потужна Автоматична Бойова гвинтівка
```

Для слов’янських мов граматичне узгодження між слотами важливе, тому INNR editor групує такі рядки разом замість того, щоб змішувати їх із загальною таблицею перекладів.

## Book / HTML Editor

**Доступ:** кнопка `📖 Book editor` у Detail Panel, коли вибрано `BOOK` record або рядок з HTML-подібною markup.

Книги й нотатки в грі використовують базову HTML-розмітку: bold, italic, paragraph breaks, font tags тощо.
Book Editor дає **split-pane preview**, щоб ви бачили, як текст виглядатиме в грі.

### Ліва панель: Source

Показує оригінальний англійський текст у read-only режимі.
Можна перемикатися між:

- **Raw** — сирий HTML;
- **Preview** — відрендерений вигляд.

### Права панель: Translation

Містить редаговане поле перекладу.
Також підтримує перемикання між **Raw** і **Preview**.

Preview стилізований під Pip-Boy: темно-зелений фон і термінальний шрифт, щоб наближено відтворити ігровий вигляд.

### Гарячі клавіші

| Комбінація   | Дія                    |
| ------------ | ---------------------- |
| `Ctrl+Enter` | Зберегти і закрити     |
| `Escape`     | Закрити без збереження |

### Поради

- Перекладайте **лише текст між тегами**, не змінюючи markup.
- Значення `font face=` перекладати не можна.
- Зберігайте `<br>` і `<p>` для правильних відступів і перенесень.
- `<img src="img://...">` не змінюйте — це внутрішні ігрові посилання.
- Періодично перемикайтеся на **Preview**, щоб перевіряти переповнення довгих рядків.
- Обидві панелі можна перемикати між Raw і Preview незалежно одна від одної.
