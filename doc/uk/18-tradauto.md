# 18 — Двигун правил TradAuto

Сторінка **TradAuto** надає двигун автоматичного перекладу на основі шаблонів, натхненний
оригінальним двигуном TradAuto. Кожне правило визначає **вихідний шаблон** (зі змінними-
заповнювачами) та **шаблон заміни**. Під час застосування правила перевіряються проти неперекладених
рядків у порядку пріоритету — перший збіг перемагає і автоматично формує переклад.

---

## Концепції

### Синтаксис шаблонів

Шаблони використовують `%VAR1%`, `%VAR2%`, … `%VARn%` як заповнювачі для довільних фрагментів тексту.
Двигун компілює кожен шаблон у регулярний вираз з нежадібними групами захоплення.

| Шаблон            | Збіги                       | Заміна            | Результат               |
| ----------------- | --------------------------- | ----------------- | ----------------------- |
| `%VAR1% Sword`    | `Iron Sword`, `Glass Sword` | `Меч %VAR1%`      | `Меч Iron`, `Меч Glass` |
| `%VAR1%'s %VAR2%` | `Piper's Coat`              | `%VAR2% — %VAR1%` | `Coat — Piper`          |
| `Stimpak`         | `Stimpak` (буквально)       | `Стімпак`         | `Стімпак`               |

### Пріоритет

Кожне правило має числовий **пріоритет** (менше = вищий пріоритет). Якщо декілька правил
підходять до одного рядка, перемагає правило з найменшим числом пріоритету.

### Обмеження сфери

Правила можна обмежити за:

- **ГРУП** (сигнатура) — наприклад, `WEAP`, `ARMO`, `NPC_`. Якщо встановлено, правило
  застосовується лише до рядків записів цього типу.
- **Поле** (шлях) — наприклад, `FULL`, `DESC`. Якщо встановлено, правило застосовується лише
  до цього конкретного поля запису.

Залиште обидва порожніми для глобального правила, яке застосовується до будь-якого рядка.

---

## Керування правилами

Відкрийте сторінку **TradAuto** з панелі навігації. Верхня секція показує форму додавання та
таблицю правил.

### Додавання правила

1. Встановіть **Пріоритет** (за замовчуванням 10).
2. Введіть **Шаблон** — шаблон мови-джерела зі заповнювачами `%VARn%`.
3. Введіть **Заміну** — шаблон цільової мови з посиланнями на ті ж змінні.
4. За бажанням встановіть **ГРУП** та/або **Поле** для обмеження сфери.
5. Додайте необов'язковий **Опис** для документування призначення правила.
6. Натисніть **Додати правило**.

Сервер валідує шаблон при створенні — якщо шаблон містить помилку, буде показано повідомлення.

### Редагування / Видалення

- Натисніть **Редагувати** у будь-якому рядку для переходу в режим інлайн-редагування.
  Змініть поля і натисніть **Зберегти**.
- Натисніть **Видалити** для видалення правила (потрібне підтвердження).
- Перемкніть прапорець **Активно** для ввімкнення/вимкнення правила без видалення.

---

## Тестування правил (пробний запуск)

Нижче таблиці правил знаходиться панель **Тестування правил**:

1. Введіть один або кілька вихідних текстів, по одному на рядок.
2. Натисніть **Тест**.
3. Для кожного рядка панель покаже:
   - Повернений переклад та ID правила (якщо правило спрацювало).
   - «немає збігу», якщо жодне правило не підходить.

Це не змінює даних — це лише попередній перегляд роботи правил.

---

## Застосування правил до мода

Панель **Застосувати до мода** дозволяє запустити всі активні правила проти неперекладених рядків мода:

1. Оберіть **Мод** зі списку.
2. Поставте прапорець **Пробний запуск** для попереднього перегляду результатів без збереження (рекомендовано спочатку).
3. Натисніть **Застосувати правила**.

У режимі пробного запуску система звітує, скільки рядків збіглися б. Зніміть прапорець і
застосуйте знову, щоб реально зберегти переклади. Збережені переклади отримають:

- **Статус:** `auto`
- **Походження:** `tradauto`
- **Модель:** `rule_<id>` (ID правила, що спрацювало)

---

## Поради

- Починайте з правил високого пріоритету (мале число) для поширених, специфічних шаблонів, а
  більші числа використовуйте для загальних правил-«ловців».
- Використовуйте панель тестування для перевірки правил перед застосуванням до цілого мода.
- TradAuto працює разом з LLM-перекладом та пам'яттю перекладів — рядки, перекладені правилами
  TradAuto, не будуть повторно перекладені іншими методами.
- Правила прив'язані до мовної пари (`src_lang` / `tgt_lang`), тому можна підтримувати окремі
  набори правил для різних цільових мов.

---

## Навчання правил з пам'яті перекладів

Панель **Навчитися правил з ПП** (нижче панелей «Тестування» та «Застосувати») автоматично
виявляє кандидатів на правила, аналізуючи шаблони в наявних перекладах.

### Як це працює

Алгоритм (натхненний підсистемою _TradAutoGRUP_):

1. Завантажує всі валідовані пари перекладів з бази даних для поточної гри та мовної пари.
2. Групує їх за **ГРУП** (сигнатура) та **Поле** (шлях).
3. У кожній групі порівнює кожну пару перекладів, шукаючи спільні **префікси** та **суфікси**
   на межах слів.
4. Відмінна середня частина стає `%VAR1%`, формуючи кандидата «шаблон → заміна».
5. Ідентичні кандидати агрегуються — лічильник **Входжень** показує, скільки унікальних вихідних
   рядків відповідають кожному шаблону.
6. Кандидати, що вже існують як активні правила, фільтруються.
7. Результати сортуються за кількістю входжень (від найбільшого).

### Використання панелі

1. Встановіть поріг **Мін. входжень** (за замовчуванням 3) — показуються лише шаблони, підкріплені
   щонайменше такою кількістю різних вихідних рядків.
2. Натисніть **Знайти шаблони**.
3. Перегляньте таблицю кандидатів:
   - **Шаблон / Заміна** — виявлені шаблони правил.
   - **ГРУП / Поле** — сфера дії (успадкована від вихідних даних).
   - **Входжень** — скільки перекладів підтверджують цей шаблон.
   - **Приклади** — розгорніть, щоб побачити зразки пар (джерело → переклад).
4. Натисніть **Додати як правило** на будь-якому кандидаті, який хочете зберегти. Його буде
   збережено як звичайне правило TradAuto з пріоритетом 100 та автоматичним описом.

### Поради

- Починайте з вищого порогу (5–10), щоб бачити лише найнадійніші шаблони.
- Після додавання правил натисніть **Знайти** знову — вже додані шаблони виключаються.
- Алгоритм навчання створює лише одно-змінні шаблони (`%VAR1%`). Для правил з кількома змінними
  створюйте їх вручну.
- Навчання правил найкраще працює з назвами ігрових предметів (зброя, броня, інгредієнти), де
  однакові префікси матеріалу/типу повторюються в багатьох записах.
