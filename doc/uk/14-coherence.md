## Що таке coherence?

Переклад є **узгодженим**, коли одна й та сама вихідна фраза завжди дає один і той самий переклад у межах мода, а бажано й у всій базі.

Приклади неузгодженості:

- `Take care, wanderer.` перекладено як `Бережись, мандрівнику.` в одному місці і як `Обережно, мандрівнику.` в іншому.
- Ім’я `Paladin Danse` перекладене по-різному в різних репліках.

Такі розходження помітні гравцям і створюють відчуття неякісної локалізації.

## Відкриття Coherence Checker

Перейдіть на сторінку **Coherence** через верхню навігацію або відкрийте маршрут `/coherence`.

Якщо груп невідповідностей не знайдено, сторінка показує прямі дії замість лише пасивного повідомлення:

- **Refresh check** — повторно запускає coherence-query
- **Open Review Queue** — одразу переводить у quality-review workflow

---

## Як читати результати

Coherence checker виводить **source strings, для яких існує більше одного distinct translation** у базі.

У верхній частині сторінки є dropdown **Language**, щоб вибрати target language для перевірки. Після зміни мови список перезавантажується автоматично.

Результати показуються як **collapsible group cards** з пагінацією по 30 груп на сторінку.
Групи відсортовані за спаданням кількості варіантів, тобто найконфліктніші рядки йдуть першими.

У header кожної картки видно:

- source text;
- бейдж із кількістю distinct translations, наприклад `2 variants`.

Після розгортання картки ви побачите **variant cards** для кожного окремого варіанта перекладу.
Вони відсортовані за популярністю: найчастіше вживаний варіант показується першим.

Кожен variant card містить:

| Елемент          | Опис                                          |
| ---------------- | --------------------------------------------- |
| Translation text | Текст конкретного варіанта перекладу          |
| Apply to All     | Поширює цей варіант на всі рядки групи        |
| String list      | Перелік рядків, що використовують цей варіант |

У списку рядків видно назву мода, EDID, signature + path та поточний статус.

## Як виправляти неузгодженості

1. Розгорніть групу.
2. Перегляньте всі variant cards і рядки під ними.
3. Вирішіть, який переклад має стати канонічним.
4. Натисніть **Apply to All** на потрібному варіанті.

Ця дія викликає `POST /api/coherence/resolve` із вибраним `translation` і груповим ключем `text_norm`.
Сервер оновлює всі рядки групи, які використовують інший переклад.

Що стається після успішного resolve:

- список coherence-груп оновлюється, і виправлена група зникає;
- invalidation торкається QA counts та редакторських даних;
- попередження `duplicate_inconsistency` прибираються автоматично.

Якщо не хочете застосовувати масову дію, можна записати назву мода, EDID або source text і вручну знайти потрібний рядок у редакторі.

---

## Коли запускати перевірку узгодженості

- Перед фінальним експортом релізу.
- Після великого LLM batch translation.
- Після імпорту перекладів від іншого перекладача.
- Після carry-over перекладів із нової версії мода.
- Для великих модів починайте з першої сторінки, бо саме там наймасовіші конфлікти.
