# 04 — Гарячі клавіші

Shortcuts діють, коли сторінка редактора у фокусі. Таблиця рядків, Dialogs і
Voice мають трохи різні набори. Більшість клавіш без модифікаторів ігноруються,
поки курсор у `input`, `select` або `textarea`.

Немає `Ctrl+H` для Search & Replace — відкривайте кнопкою на тулбарі.
Немає пагінації `Page Up` / `Page Down`: таблиця рядків — infinite scroll.

## Таблиця рядків

| Комбінація     | Дія                                                                                  |
| -------------- | ------------------------------------------------------------------------------------ |
| `Ctrl+S`       | Зберегти поточний переклад                                                           |
| `Ctrl+Enter`   | Зберегти з textarea панелі деталей                                                   |
| `Enter`        | Відкрити панель деталей або сфокусувати textarea, якщо вона вже відкрита             |
| `Escape`       | Закрити context menu, панель деталей або скинути selection                           |
| `?`            | Overlay з довідкою                                                                   |
| `↑` / `↓`      | Перемістити фокус; зациклюється на кінцях **завантаженого** списку                   |
| `Ctrl+Shift+E` | Відкрити / закрити панель деталей (на сфокусованому або першому завантаженому рядку) |
| `Ctrl+Shift+C` | Скопіювати source у поле перекладу                                                   |
| `Ctrl+Shift+X` | Очистити поточний переклад                                                           |
| `Space`        | Перемкнути selection сфокусованого рядка                                             |
| `Ctrl+A`       | Вибрати або зняти вибір з **усіх рядків за фільтром** (не лише видима сторінка)      |

`Ctrl+Shift+C` не підставляє TM. `Ctrl+Shift+X` не викликає LLM.

`N` у таблиці рядків **не** призначена. Вона працює в Dialogs і Voice.

Якщо браузер перехоплює `Ctrl+S`, візьміть чистий профіль або вимкніть конфліктне розширення.

## Dialogs

На вкладці Dialogs (Bethesda). Акорди з модифікаторами працюють і під час
редагування; звичайні клавіші ігноруються, поки курсор у полі.

| Комбінація            | Дія                                                  |
| --------------------- | ---------------------------------------------------- |
| `1` / `2` / `3` / `4` | Scope: topics, branches, scenes, conversations       |
| `Alt+↑` / `Alt+↓`     | Попередня / наступна група в навігаторі              |
| `↑` / `↓`             | Попередня / наступна репліка в транскрипті           |
| `/`                   | Фокус у пошук                                        |
| `N`                   | Наступна незавершена репліка                         |
| `P`                   | Відтворити озвучку сфокусованої репліки, якщо вона є |
| `Enter`               | Редагувати сфокусовану репліку                       |
| `Escape`              | Зняти фокус (коли не редагуєте)                      |

## Voice

Ті самі клавіші списку реплік, що в Dialogs (`↑`/`↓`, `N`, `P`, `Enter`,
`Escape`). Немає перемикача scope і кроку груп `Alt+↑`/`Alt+↓`. Див.
[Озвучка](09-voice.md).

## Модалка Book / HTML

`Escape` закриває. `Ctrl+Enter` зберігає.
