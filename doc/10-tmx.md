## What is TMX?

**TMX 1.4b** is an open XML standard for exchanging Translation Memory data
between different translation tools.
Virtually every professional CAT tool supports TMX import and export.

A TMX file contains translation unit pairs:
```xml
<tu>
  <tuv xml:lang="en"><seg>Take care, wanderer.</seg></tuv>
  <tuv xml:lang="uk"><seg>Бережись, мандрівнику.</seg></tuv>
</tu>
```

## Use Cases

- **Team collaboration** — a translator working in OmegaT can import your TMX
  as a reference, or export their TMX for you to merge back.
- **Backup and migration** — export the full TM before moving to a new machine.
- **Seeding from existing translations** — if you have a translation file from
  another project, convert it to TMX and import it to jump-start your TM.
