## Overview

Before exporting your translation, the QA engine scans every translated string
and flags potential problems.

QA is not blocking — you can export even if issues exist — but reviewing
QA flags ensures a polished, professional localisation.

## QA Issue Types

| Issue Type | Description |
|------------|-------------|
| **Missing translation** | Source has text but translation is empty |
| **Broken placeholder** | A token like `<Alias=Player>` is missing or malformed in translation |
| **Extra placeholder** | Translation contains a placeholder not present in the source |
| **Max length exceeded** | Translation is longer than the field's allowed character/byte limit |
| **Forbidden character** | Translation contains a character not supported by the game engine |
| **Coherence violation** | Same source text is translated differently in two different strings |

## Severity Levels

| Severity | Meaning | Recommended Action |
|----------|---------|-------------------|
| **Error** | Will certainly cause problems in-game (broken placeholder, max length) | Must fix before export |
| **Warning** | Likely to cause issues or look unprofessional | Fix if possible |
| **Info** | Minor suggestion or style note | Review at your discretion |
